# ozolu-darbnica

Ozolu darbnīcas public in-character intranet for the itBDA course.

Current release: P03 — a Līga, Māris and Rūta conversation about recognising implausible operational records and checking whether a control catches them, without turning the message board into a task instruction page.

The Sarunas view keeps earlier weeks: a week selector (P03, P02) with Monday–Friday day filters, days without messages disabled, and a short earlier-week section in the home feed. No instructor material, future-period content or answers are included.
